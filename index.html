TF2 Patch Notes Generator

Fake but believable Team Fortress 2 update notes, written by a small LLM that runs entirely in your browser.

On phones this defaults to the smallest model to save download size and GPU memory. First load can be a few hundred MB (then cached). WebGPU needs recent Chrome on Android, or Safari with WebGPU. If the tab crashes or runs out of memory, switch to the smaller model.
WebGPU is not available in this browser.

This app needs WebGPU to run the model locally. Try:

  • Chrome or Edge 113+ on desktop
  • Recent Chrome on Android
  • Safari 26+ (WebGPU enabled)
  • Firefox with dom.webgpu.enabled turned on in about:config
